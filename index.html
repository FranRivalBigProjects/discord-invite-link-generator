What Each Part of the Link Does

The invite link tells Discord which application to add (client_id), what it is allowed to request (scope), and which permissions to pre-select in the authorization screen (permissions, as a single integer). The person adding your bot can still uncheck permissions before confirming, so this link sets sensible defaults rather than forcing access.

Where to Find Your Client ID

Your client ID is listed on the General Information page of your application in the Discord Developer Portal, right under the application name.
